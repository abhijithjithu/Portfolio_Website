# Served assets

Everything here is copied to the site as-is.

- `*.webp` — generated. Do not edit by hand: put the full-size original in
  `assets-src/` and run `npm run images`.
- `resume.pdf` — replace the file to update the résumé links.
- `og-preview.png` — the 1200×630 link-preview card. Kept as PNG because
  social crawlers do not reliably accept WebP.
- `favicon.svg`
