# Your Personal Assets

Place your files in this folder before running `npm run dev`.

## Expected files:

| File | Purpose |
|------|---------|
| `profile.jpg` (or `.png`) | Profile photo displayed in the hero section |
| `resume.pdf` | Downloadable resume linked in the footer |

## How to use:

1. Drop your **profile photo** here and name it `profile.jpg` (or `profile.png` — update `DynamicPitch.jsx` if using `.png`)
2. Drop your **resume PDF** here and name it `resume.pdf`
3. Run `npm run dev` — everything will load automatically. No code changes needed.

## Note on image format:
- Supported: `.jpg`, `.jpeg`, `.png`, `.webp`
- Recommended size: 400×400px or larger (square crop looks best)
